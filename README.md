## 概要
本リポジトリは、Ruby on Rails を用いて開発した EC サイトです。
商品購入機能や管理者機能を含め、実務を想定した基本的な EC サイトの構成を実装しています。

## 使用技術
- Ruby 3.2.1
- Rails 7.0.0
- PostgreSQL 14
- Bootstrap
- 開発環境：Docker
- 本番環境：Heroku
- 画像保存：Amazon S3

## 機能一覧
### 商品機能
- 商品一覧・詳細表示
- 商品画像の表示

### 管理者機能
- Basic 認証による管理者画面へのアクセス制御
- 商品管理（CRUD）
- 注文管理

### カート・チェックアウト機能
- カート追加・削除
- 注文確定処理
- チェックアウト時に購入明細をメール送信

### プロモーションコード機能
- プロモーションコードの適用
- 割引金額の自動計算
- 注文金額への反映

## 工夫した点
- 購入フローの一連の処理を実装（カート → チェックアウト → 注文作成 → 注文明細作成 → メール送信）
- セッション単位でカートを管理し、複数ユーザーが同時利用してもデータが混在しない設計とした
- プロモーションコードは管理コマンドで事前生成し、データベースで管理
- プロモーションコードは session を利用して管理し、1回のみ適用できるよう制御
- 業務利用を想定した独自の管理画面を実装
- 管理画面はBasic認証と環境変数による認証情報管理で保護
- partial を活用してビューの共通部分を再利用し、コードの重複を削減
- 本番環境は Heroku にデプロイし、クラウド上でアプリケーションを公開
- 画像保存先として Amazon S3 を利用し、アプリケーションサーバーの負荷軽減とスケーラビリティを確保
- 環境変数を用いてAWS認証情報を管理し、セキュリティを考慮した構成とした
